# agri-rcf.github.io

Website of the Faculty of Agriculture Research Core Facilities (The Hebrew University of Jerusalem, Rehovot campus).

## Pages

- `index.html` – hub: facilities overview, contributing, contacts
- `icp.html` – Plasma Spectrochemistry (ICP-OES / ICP-MS) Laboratory: services, equipment, limits of quantification, sample submission, FAQ, team
- `styles.css`, `site.js`, `assets/favicon.svg` – shared design, identical to csi-microscopy.github.io (IBM Plex type, CSS tokens, dark mode that follows the system and a persisted toggle)
- `assets/icp/` – images, the sample submission form (PDF and Word) and the original LOQ tables used on the ICP page; source material is in `assets/ICP-LAB-WEBSITE2023/`

## Editing

Plain HTML and CSS, no build step. Edit, commit, push; GitHub Pages publishes `main`.
